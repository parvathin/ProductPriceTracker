# Product Price Tracker

## Overview

The Product Price Tracker is a frontend application that:
- Fetches product data from the [FakeStore API](https://fakestoreapi.com/).
- Allows users to select a product and set a desired price alert.
- Periodically checks the product's price.
- Triggers an in-app notification when the product price meets or falls below the set target.

  Technology Stack

- Frontend: HTML, CSS, JavaScript
- **Frameworks/Libraries:** Bootstrap 4.5.2 for styling
- API: given FakeStore API
